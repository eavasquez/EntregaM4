# Entrega M4

Este repositorio contiene la entrega final del Módulo 4 del curso. El proyecto fue desarrollado como parte de las actividades prácticas solicitadas en el módulo y reúne todos los archivos necesarios para ejecutar la entrega.

## 📁 Contenido del Repositorio

El proyecto está compuesto por los siguientes archivos:

- `index.html` – La página principal del proyecto.
- `style.css` – Los estilos relacionados a la interfaz.
- `app.js` – Lógica principal del proyecto implementada en JavaScript.
- Documento PDF con la descripción del proyecto y su desarrollo (*Proyecto Módulo ABP.pdf*).

## 🧩 ¿Qué hace este proyecto?

Este trabajo corresponde a una entrega académica orientada a aplicar los conocimientos desarrollados en el módulo. Contiene:
- Estructura básica de HTML, CSS y JavaScript para una aplicación web.
- Componentes y estilos organizados para permitir su extensión y análisis.
- Documentación interna del proyecto con los objetivos y criterios de evaluación.
